Skillog 吉祥物

一张基准图锁定角色，一条指令切换不同 Skill 场景。

PROJECT SKILL

先锁角色，再换场景。

项目内置 $skillog-robot-illustrations。它会自动携带基准图，固定机器人的头身、面屏、天线、耳罩、紫色 S 与纯净背壳；轻微潦草感只由提示词控制，不改变角色结构。

  1. 01
    下载或克隆项目

    完整 Skill 位于 .agents/skills/，会随 Git 仓库一起保存。

  2. 02
    在 Codex 中打开项目

    Codex 会识别项目级 Skill，不需要重新寻找角色设定。

  3. 03
    说清一个结果和动作

    默认生成 3:4 小红书配图；文章正文图可指定为 16:9。

可直接复制
Use $skillog-robot-illustrations 为「Skill 名称」生成一张 3:4 的 Skillog 吉祥物手绘配图。核心结果是「想表达的结果」，让机器人亲自完成「具体动作」。
