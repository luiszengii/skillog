## 正文

第 001 个 Skill：`find-skills`

想找一个能完成具体任务的 Agent Skill，不用先知道它叫什么。

输入一句任务描述，它会先看热门榜，再搜索相关 Skill，并把来源、安装量和安装入口一起给你。

我用「social media content」实测了一次，返回了 20 个候选，包括内容策略、内容日历、素材复用和趋势研究。

它比较适合刚开始用 Codex、Claude Code 或 Cursor，想扩展能力但不知道从哪里找的人。

安装命令：

`npx skills add vercel-labs/skills --skill find-skills`

提醒：安装量不等于安全或效果。当前页面显示 2 项审计通过、1 项警告，安装前还是要看看源仓库和 `SKILL.md`。
