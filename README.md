# 万术录 Skillog

每日 AI Skill 的内容、数据与决策档案。

## 构建 GitHub Pages

```bash
npm install
npm run build:site
```

构建结果位于 `docs/`，可由 GitHub Pages 从 `main` 分支的 `/docs` 目录发布。

## 数据分工

- `data/notion-export.json`：Notion 结构化数据快照
- `posts/`：每条帖子的四图、文案、结果与流量截图
- `templates/`：四卡 HTML/CSS 模板
- `docs/`：静态网页发布目录

## 公开性提醒

GitHub Pages 网页通常公开可访问。当前快照包含内部策略与未来流量数据，发布前必须确认公开范围。
